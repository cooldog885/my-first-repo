# 截图与素材指南

上架需要：512×512 高清图标、1024×500 特色图、若干手机/折叠屏截图。这些需要**真实运行界面**，无法在纯代码环境生成，以下是可执行的操作方法。

## 一、用 ADB 自动截图（连上手机或模拟器后）

把下面脚本保存为 `capture.ps1`，在已连接设备时运行即可批量截图到 `screenshots/`：

```powershell
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
$pkg = "com.example.foldledger"
$out = "screenshots"; New-Item -ItemType Directory -Force -Path $out | Out-Null
& $adb shell am start -n "$pkg/.MainActivity"
Start-Sleep -Seconds 2
# 1) 记账页（单栏）
& $adb shell screencap -p /sdcard/shot_entry.png; & $adb pull /sdcard/shot_entry.png "$out\01_entry.png"
# 2) 明细页（点底部“明细”）
& $adb shell input tap 540 2200   # 视设备调整底部 Tab 坐标
Start-Sleep -Seconds 1
& $adb shell screencap -p /sdcard/shot_list.png; & $adb pull /sdcard/shot_list.png "$out\02_list.png"
# 3) 分析页（点底部“分析”）
& $adb shell input tap 900 2200
Start-Sleep -Seconds 1
& $adb shell screencap -p /sdcard/shot_analysis.png; & $adb pull /sdcard/shot_analysis.png "$out\03_analysis.png"
# 4) 双栏（折叠屏内屏或 7.1" 模拟器）
#    直接在同一设备展开/切到 sw>=720dp 后截图：
& $adb shell screencap -p /sdcard/shot_dual.png; & $adb pull /sdcard/shot_dual.png "$out\04_dual.png"
Write-Output "截图已保存到 $out"
```

> 底部 Tab 坐标需按你设备的分辨率微调（可用 `adb shell wm size` 查看分辨率）。

## 二、导出 512×512 高清图标
当前图标是矢量 `app/src/main/res/drawable/ic_launcher.xml`，可无损放大。两种方式：
- **Android Studio**：右键 `ic_launcher.xml` → *Export to PNG*，选 512×512；或 *File → New → Image Asset* 生成全套 mipmap。
- **在线工具**：把矢量内容贴到任意 “SVG/PNG 转换” 网站，导出 512×512 PNG（背景透明即可，商店会自动加圆角/背景）。

## 三、1024×500 特色图（Feature Graphic）
Google Play 要求，建议：
- 纯色/渐变背景 + 应用名 + 一句 slogan（如「纯本地 · 护隐私的折叠屏记账本」）。
- 不要放会被圆角裁切的关键文字到边缘。
- 用 PowerPoint / Figma / 任意作图工具做，导出 1024×500 PNG。

## 四、截图内容建议（覆盖核心卖点）
1. 记账录入页（含自定义分类「＋」入口）
2. 明细页（按日期分组）
3. 分析页（饼图 + 折线 + TOP5）
4. 折叠屏内屏双栏（记账 + 明细/分析）
5. 顶栏「导出/导入 CSV」菜单（数据安全卖点）
